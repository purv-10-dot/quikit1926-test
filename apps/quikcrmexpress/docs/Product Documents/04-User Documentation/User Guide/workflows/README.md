# Common workflows

These guides follow a job from start to finish across several modules, rather than describing one feature at a time.

| Workflow | What it covers |
|---|---|
| **[From new lead to converted customer](lead-to-conversion.md)** | Capture → qualify → work → convert into a contact, account and deal |
| **[From a call to a booked follow-up](call-to-follow-up.md)** | Calling, recording the outcome, and making sure the next step is scheduled |
| **[Why a record disappeared from my list](when-records-disappear.md)** | Diagnosing the most common "where did it go?" situations |

## Choosing a starting point

| If your job is… | Start with |
|---|---|
| Getting a new prospect into the system properly | [From new lead to converted customer](lead-to-conversion.md) |
| Working a call list | [From a call to a booked follow-up](call-to-follow-up.md) |
| Pulling a segment of leads for a campaign | [Advanced filters](../leads/advanced-filters.md), then [Selection and bulk actions](../leads/bulk-actions.md) |
| Loading a spreadsheet of prospects | [Import leads](../leads/import.md) |
| Getting data out to a spreadsheet | [Exporting leads](../leads/export.md) — read the limitations first |
| Understanding why you can't see something | [Why a record disappeared](when-records-disappear.md) |

## Workflows not covered here

Some capabilities exist in the product but are not part of the supported navigation in this release, so they are deliberately not documented as workflows. Your administrator can advise if you believe you need them.
