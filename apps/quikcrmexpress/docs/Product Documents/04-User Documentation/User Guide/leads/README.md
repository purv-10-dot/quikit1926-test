# Leads

Leads are prospective customers. Everything in QuikCRM starts here: you capture a lead, work it through your pipeline with calls and activities, and eventually convert it into a contact, an account and a deal.

**Where to find it:** Sidebar → **Leads**

**Available to:** Sales User, Sales Manager, Marketing User, Administrator. Finance Users do not have the Leads module.

---

## The three views

The Leads module opens with a tab bar offering three ways to look at the same data:

| Tab | Use it for |
|---|---|
| **All Leads** | The main working table — filter, sort, select and act on leads |
| **Lists** | Your saved filters, shown as a list with record counts |
| **Kanban** | A stage-by-stage board you can drag cards across |

## A typical day

1. Open **Leads** and pick a saved view, or apply a filter.
2. Work down the list — call, log activity, update status.
3. Move leads forward using the stage stepper on the lead's page, or by dragging on the Kanban board.
4. Convert the ones that are ready.

For the full end-to-end path, see [From new lead to converted customer](../workflows/lead-to-conversion.md).
