1. Overview & Tech Stack

The QuikSkill LMS web client is a single-page React application served by Vite. It renders seven role-specific experiences from one bundle, driven by the tenant's feature flags and the logged-in user's role. It talks to the NestJS REST API and two Socket.IO namespaces, and performs heavy in-browser work: SCORM playback, MediaPipe face-proctoring, resumable uploads, and PDF generation.

2. Routing, Client Auth & Route Protection

All routing lives in src/App.tsx using <Routes>/<Route>. Auth state is held in browser storage (no server session):

  • sessionStorage.access_token — JWT attached to every API request.
  • sessionStorage.user — JSON user object (role, secondaryRole, tenantId, …).
  • localStorage.activeRole — currently active role for multi-role users (set by RoleSwitcher).
  • localStorage.quickskill-theme, i18nextLng — theme & language preferences.

Route Guards (3 wrappers in App.tsx)

GuardLogic
PrivateRouteRenders children only if access_token exists, else redirects to /login (spinner while checking).
RoleProtectedRouteChecks user.role / user.secondaryRole / activeRole against an allowedRoles list; unauthorized users are bounced to their own dashboard via getDashboardPath().
RedirectIfAuthenticatedWraps /login — logged-in users are sent to their role dashboard so they never see the login page again.

4. API / Data Layer, Env Vars & Socket.IO

Axios instance — src/utils/api.ts

const API_BASE_URL = import.meta.env.VITE_API_URL || 'https://quikskillsbackend.quikit.ai';
const api = axios.create({ baseURL: API_BASE_URL, headers: { 'Content-Type': 'application/json' } });

// Request: attach JWT; drop Content-Type for FormData (let browser set boundary)
api.interceptors.request.use(cfg => {
  const token = sessionStorage.getItem('access_token');
  if (token) cfg.headers.Authorization = `Bearer ${token}`;
  if (cfg.data instanceof FormData) delete cfg.headers['Content-Type'];
  return cfg;
});
// Response: on 401 clear session and redirect to /login?error=...
api.interceptors.response.use(r => r, err => {
  if (err.response?.status === 401) { sessionStorage.clear(); window.location.href = '/login?error=...'; }
  return Promise.reject(err);
});

Socket.IO — src/utils/socket.ts

Connects to ${VITE_API_URL}/messages with auth:{token}, transports websocket+polling, infinite reconnection. disconnectMessagesSocket() is called on logout from every layout. The exam timer uses the /exams namespace.

5. State Management, Contexts & i18n

State is entirely React Context — no Redux/Zustand. Three providers wrap the app (BrandingProvider → FeatureProvider → app):

Feature flags (FeatureContext): showCourses, showScormContent, showCompliance, showManagerDashboard, showBatches, showSchedule, showAttendance, showHomework, showCredits, showPayouts, showVideoClasses, showParentPortal, showMessaging, showCertificates, showAnalytics, showNotifications, showMultiLanguage. FeatureRoute component gates routes/menu items by these flags.

i18n (src/i18n/config.ts): i18next + react-i18next + language detector. Languages: English (en), Hindi (hi), Tamil (ta), Telugu (te), Kannada (kn), Marathi (mr), Bengali (bn). Detection: localStorage.i18nextLng → browser; fallback en. JSON dictionaries in src/i18n/locales/. LanguageSwitcher component toggles language.

8. Real-time & Media Features

  • Messaging (Socket.IO /messages): realtime send/receive, typing indicators, presence, reactions, group chat; auto-reconnect; disconnect on logout.
  • Exam timer (Socket.IO /exams): server-authoritative countdown — timerSync every 30s, warnings at 5min/1min, forceSubmit at timeout.
  • Face proctoring (MediaPipe): in-browser webcam analysis for quizzes/exams; violations logged server-side.
  • Behaviour proctoring: fullscreen enforcement, tab/visibility, copy/paste/print/right-click/shortcut detection.
  • Video: react-player (YouTube/Vimeo/HLS/MP4) for lessons; Jitsi/Zoom/Meet embeds for live classes (VideoClassPage); join/leave attendance tracking.
  • SCORM playback: UniversalLMSPlayer tracks lesson_location (slide index / scroll px / playback seconds), score, completion → /player/sync.
  • Resumable uploads: tus-js-client for large media (pause/resume) → S3 via backend TUS endpoint.
  • PDF / canvas: jsPDF + html2canvas for certificates & report export; canvas-confetti for completion celebrations; react-pdf for PDF lessons.
  • Offline: useOfflineDetection buffers progress locally and syncs on reconnect.

Vite / ReactNext.js (App Router)

Key insight: The REST contract is unchanged by the backend's Mongo→Postgres switch, so the frontend migration is purely a Vite→Next.js framework port: convert the route table to the App Router, move auth from browser storage to cookies, and wrap browser-only components ('use client'/ssr:false). Business logic, API calls, contexts and Tailwind styling carry over directly.
