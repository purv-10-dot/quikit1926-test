1. What is QuikIT HRMS?

QuikIT HRMS is a Human Resources Management System. It helps a company manage its people — hiring, onboarding, attendance, leaves, payroll, performance, documents, assets, and more. Everything in one place. Built for HR teams, managers, and employees.

In simple words: QuikIT HRMS = digital HR office. No paperwork. Click, fill, submit.

Who uses it?

HR ManagerAdds employees, runs payroll, approves leaves, tracks compliance
EmployeeChecks in, applies leave, views payslip, updates profile
ManagerApproves team leaves, reviews performance, assigns tasks
CEO / FounderViews org analytics, headcount, attrition
IT / AdminConfigures settings, manages roles, checks audit logs

How to log in

1 Open the QuikIT HRMS URL in a browser (Chrome, Firefox, Safari, Edge)
2 Click "My Space" in top blue bar — that is your personal workspace
3 Left sidebar shows all modules. Click any module to open it.

4. Common Workflows

🎯 New hire end-to-end

  1. Recruit → Create Requisition → post job
  2. Candidate applies → Pipeline moves to Interview
  3. Interview completed → scorecard filled
  4. Offer sent → candidate accepts
  5. Onboarding → Add Candidate (big form)
  6. Template tasks auto-created (ID proof, laptop, orientation)
  7. Tasks completed → Complete Onboarding button → employee becomes Active

🏖️ Apply & approve leave

  1. Employee: Leave Tracker → Apply Leave → fill form → submit
  2. Manager: Team Leaves → Pending Approvals → Approve/Reject
  3. Employee sees updated status + balance

💰 Run monthly payroll

  1. Payroll → Run Payroll → select month → Process
  2. System auto-computes Basic + HRA + deductions (PF, PT, TDS)
  3. Review → Approve → Lock → Generate Payslips → Pay
  4. Employees see payslip in Payroll → Payslips

📄 Generate offer letter from template

  1. Documents → Templates → New Template (with {{firstName}}, {{ctc}}, etc.)
  2. Click "Generate" → fill placeholder values → document created
  3. Send via E-Sign for signatures

💻 Asset assignment

  1. Assets → Add Asset (laptop, serial, brand, price)
  2. Open asset → Assign → pick employee + expected return date
  3. Later: Return → set condition → auto-flip to Available / InRepair / Lost

💸 Expense reimbursement

  1. Expenses → New Claim → select policy → fill amount + receipt URL
  2. Submit → flows through approval chain (Manager → Finance)
  3. Mark Paid → reflected in payslip as reimbursement

5. Quick Tips

Keyboard: Use Ctrl+F to search within tables.
Filters: Most tables have filter icons (funnel). Click to open filter drawer.
3-dot menu: Export / Import / PDF / Print available on most pages.
Drafts: Always save as draft first if unsure. Submit later.
Approvals: Once approved, many actions cannot be undone. Review before clicking.

6. FAQ

Q: Forgot to check in?

Go to Attendance → Attendance Summary → click past day → Regularization request.

Q: Payslip shows wrong amount?

Contact HR. Payroll is locked after processing. Corrections happen via Supplementary payroll run.

Q: How do I delegate leaves while on vacation?

Delegations → New Delegation → pick delegatee + date range + select "Leave" module.

Q: Where do I see my expense refund?

Expenses → My Claims → check status. Once "Paid", appears in next payslip as reimbursement.

Q: Can employees edit their own profile?

Yes. People → Employee Directory → click own name. Some fields (salary, department) locked to HR.

Q: How do I bulk-add employees?

People → Bulk Import → upload CSV with columns: firstName, lastName, workEmail, departmentCode, jobTitle, dateOfJoining. Dry-run first to validate.

Q: AI Chatbot says strange things?

AI Copilot is backed by QuikIT AI service. Responses depend on model. Verify sensitive info with HR before acting.
