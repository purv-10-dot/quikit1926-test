# Email Templates by App — Detailed Reference

**Purpose:** A shareable, app-wise reference of every email template in the QuikIT platform — the scenario that triggers each one, who receives it, and a screenshot of the rendered email.

**Scope:** All apps in the monorepo that send email. Ten of the eleven apps send templated emails.

**Screenshots:** each template below embeds its rendered preview from [`email-template-screenshots/`](./email-template-screenshots/). Images are named `<app>__<template>.png` and live in a per-app subfolder. All 56 screenshots were generated by rendering the actual template code with sample data — see the folder's [README](./email-template-screenshots/README.md) for how they were produced. *(Sample data throughout: "Rishika Sharma", "Acme Corp", fake emails/amounts — no real data.)*
