07

Cross-cutting conventions

Patterns every one of the four models follows.

Primary keys

Every model uses id String @id @default(cuid()).

Tenant scoping

Every model carries an indexed orgId String. Per repo standard, all queries must filter by orgId.

Soft deletes

An indexed deletedAt DateTime? marks records deleted rather than removing rows.

Audit timestamps

createdAt @default(now()) and updatedAt @updatedAt on all four models.

Ownership

A denormalized ownerId / ownerName pair rides on all four models.

Money

Amounts use Decimal @db.Decimal(18, 2) with a companion *Currency string (default "INR").
